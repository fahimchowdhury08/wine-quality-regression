# Wine Quality Prediction (Regression)

Predicting red wine quality scores from physicochemical, lab-measured properties using regression.

## Overview

This project applies regression techniques to the UCI Wine Quality dataset to
predict a wine's quality score (0–10) from measurable chemical properties such
as acidity, sugar, sulfur dioxide levels, pH, and alcohol content.

## Dataset

- **Source:** UCI Machine Learning Repository — Wine Quality Data Set
- **Link:** https://archive.ics.uci.edu/dataset/186/wine+quality
- **Citation:** Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality [Dataset]. UCI Machine Learning Repository.
